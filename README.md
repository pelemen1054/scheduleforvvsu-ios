# ВВГУ timetable — iOS

iOS-версия приложения для просмотра расписания ВВГУ. Проект разрабатывается отдельно от Android-версии.

## Технологии

- Swift
- SwiftUI
- XcodeGen
- GitHub Actions (сборка на macOS)

## Текущий статус

**Прототип 0.1.0.** Добавлен первый экран интерфейса и автоматическая сборка приложения для iOS Simulator.

Пока используются демонстрационные занятия. Подключение к реальному расписанию ВВГУ, поиск групп и преподавателей, избранное, кэширование и уведомления ещё предстоит реализовать.

## Сборка

GitHub Actions запускается при push в `main` или вручную через вкладку **Actions**. Текущий workflow собирает приложение для iOS Simulator без подписи.

Артефакт симулятора **не является IPA для установки на iPhone**. Для установки на реальные устройства потребуется отдельная настройка подписи и подходящий способ распространения.
