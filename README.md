# ВВГУ timetable — iOS

iOS-версия приложения для просмотра расписания ВВГУ. Разрабатывается отдельно от Android-версии.

## Текущая версия

**1.0.4 — ранняя разработка.** Основные экраны и подключение к источникам расписания находятся в работе; совместимость с реальными страницами ВВГУ нужно проверить на сборке и тестировании.

## Возможности

- Поиск групп и преподавателей с подсказками.
- Загрузка расписания группы или преподавателя с сайта ВВГУ.
- Просмотр занятий по дням и выбор даты в календаре.
- Избранные группы.
- Локальный кэш расписания и отображение времени последнего обновления.
- Автообновление при запуске.
- Напоминания о занятиях с настройкой времени и уведомлениями после длинных окон.
- Светлая/тёмная тема и выбор акцентного цвета.
- Настройки, очистка кэша и ссылки на сайт, GitHub и поддержку.

Некоторые функции пока являются первичной реализацией и требуют проверки на реальных данных. Проект не является официальным приложением ВВГУ.

## Сборка и релизы

- GitHub Actions собирает приложение для iOS Simulator на macOS при изменениях в `main`.
- Готовый ZIP сборки симулятора сохраняется в артефактах Actions.
- Файл `VERSION` — источник номера версии; версия для текущего этапа: `1.0.4`.
- Изменения фиксируются в [CHANGELOG.md](CHANGELOG.md).
- Для публикации релиза создай тег, совпадающий с номером из `VERSION`, с префиксом `v` (например, `v1.0.4`). Workflow проверит соответствие версии, соберёт приложение и опубликует GitHub Release с журналом коммитов.

**Важно:** сборка для iOS Simulator не является IPA и не устанавливается на обычный iPhone. Для установки на устройства потребуется отдельная подпись и подходящий способ распространения.
