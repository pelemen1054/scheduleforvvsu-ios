# Журнал изменений

Все заметные изменения iOS-версии фиксируются здесь. Полный журнал коммитов также автоматически добавляется в описание GitHub Release при публикации тега версии.

## [1.0.4] — начальная разработка

- Создан отдельный iOS-проект на SwiftUI.
- Добавлены экраны расписания и настроек в стиле Android-версии.
- Добавлены поиск групп и преподавателей с подсказками и загрузка расписания с сайтов ВВГУ.
- Добавлены выбор даты, избранные группы, ручное обновление и автообновление при запуске.
- Добавлены локальный кэш, время последнего обновления и сообщение об использовании сохранённых данных.
- Добавлены светлая/тёмная тема и семь акцентных цветов.
- Добавлены настройки локальных напоминаний о занятиях и тестовое уведомление.
- Настроена автоматическая сборка для iOS Simulator через GitHub Actions.
- Подключение к расписанию и уведомления требуют дополнительной проверки на реальных данных и устройствах.
- Сборка для симулятора не предназначена для установки на обычный iPhone.
