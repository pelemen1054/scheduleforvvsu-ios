# Журнал изменений

Все заметные изменения iOS-версии проекта фиксируются в этом файле.

## [1.0.4] — начальная разработка

- Создан отдельный iOS-проект на SwiftUI.
- Добавлен предварительный экран расписания с переключением «Группа / Преподаватель».
- Добавлена навигация по датам и вкладка настроек.
- Добавлена настройка светлой и тёмной темы.
- Настроена автоматическая сборка для iOS Simulator через GitHub Actions.
- Пока используются демонстрационные занятия; подключение к реальному расписанию ещё не реализовано.
- Сборка для симулятора не предназначена для установки на реальный iPhone.
